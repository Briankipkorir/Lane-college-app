# Lane College App

The Lane College App is an iOS application built with SwiftUI to help Lane College students access important campus information, services, academic resources, athletics information, communication tools, and appointments from one place.

## Purpose

The goal of this project is to create a modern, colorful, and student-friendly mobile application that improves access to Lane College resources and helps students stay connected with campus life.

## Main Features

- Student and faculty login
- Campus announcements
- Class and school group chats
- Student profile
- Academic information
- Assignments
- Blackboard and school links
- Campus map
- Building and room finder
- Dorm and housing information
- Campus directory
- Cafeteria information
- Appointment scheduling
- Nurse appointments
- Athletic trainer appointments
- Academic advisor appointments
- Campus security resources
- Anonymous safety reporting
- Athletics information
- Team rosters and schedules
- Faculty and staff directory
- Lane College history and information
- Custom appearance and theme settings
